# 확인 질문 정리본 (대표님 · 서버 담당)

`dashboard-spec.md` 6절의 미확인 항목을 전달용으로 풀어 쓴 문서다. 질문마다 **왜 필요한지**, **답이 없을 때의 현재 가정**, **답에 따라 바뀌는 곳**을 적었다.

- 답을 받으면 `dashboard-spec.md` 6절 체크리스트를 `[x]`로 바꾸고 확정 사항 표에도 옮긴다(사용자가 "확인됐다"고 말한 것만).
- 이 문서의 "답" 칸에는 받은 답과 날짜를 적는다.
- 프로토타입을 만든 뒤 이 문서를 다시 고친다(질문 추가·삭제, 가정 갱신).
- 상태: **초안 (2026-10-13), 프로토타입 후 개정 예정**

| A5 | 홈에 항상 보여야 하는 수치와 이상 기준값은 무엇인가요? | 홈은 "지금 정상인가"에 답하는 화면이라 수치를 최소로 골라야 한다. | 함수율, 전체 적재율, 시스템 상태. 적재율 80% 이상이면 주의 | 홈 상단 카드, 서버 기준값(서버 설정) |
| A6 | 압축기 이후 공정과 기기 목록은 무엇인가요? | 5단계 확장(공정 이어 붙이기)의 범위를 정한다. | 압축기 1대까지만 | 기기 ID 목록, 장면 구성 |
| A7 | 현장 카메라는 어떤 종류인가요(IP 카메라 또는 녹화 장비)? | 영상을 앱에서 쓸 수 있는 형태로 바꾸는 방식이 달라진다. | 카메라 1대 이상, RTSP를 서버가 HLS로 변환 | CCTV 방식(HLS·WebRTC) |

## B. 서버 담당자께

| # | 질문 | 왜 필요한가 | 답이 없을 때 가정 | 바뀌는 곳 |
| --- | --- | --- | --- | --- |
| B1 | 로그인, 토큰 발급, 요청마다 권한 검증이 가능한가요? 안 되면 얇은 게이트웨이를 누가 만드나요? | 앱은 권한을 판단하지 않고 서버가 차단한다는 전제다. | 서버가 검증한다 | 인증 API, 일정 |
| B2 | 현장 밖 접속을 받는 서버의 보안 설정은(HTTPS, 로그인 시도 횟수 제한, 접속·조작 기록, 필요하면 VPN)? | 외부 접속을 로그인만으로 보호하는 구조라 서버 쪽 보안이 필수다. | HTTPS와 로그인 시도 제한은 서버가 한다 | 서버 보안 설정, 접속 방식 |
| B3 | 수동 조작을 받으면 서버가 자동 운전을 어떻게 멈추고 넘겨주나요? 현장 안전 장치와는 어떻게 연동되나요? | 앱의 조작이 자동 운전과 충돌하지 않아야 하고, 안전은 앱이 아닌 현장 인터록이 맡는다. | 서버가 `409`로 불가 사유를 돌려준다 | 명령 처리와 오류 표시 |
| B4 | 관절 각도와 그리퍼 값을 초당 10~20회로 줄 수 있나요? 안 되면 단계와 진행률만 줄 수 있나요? | 로봇팔을 실제 움직임에 맞추는 방식을 정한다. | 초당 10~20회 제공(1순위). 안 되면 진행률(2순위), 정해진 동작 반복(최후) | `realtime`, `scene` 구동 방식 |
| B5 | 로봇 기종, 축 수, 각도 단위와 영점, 링크 길이는(사양서나 URDF)? | 3D 로봇팔 모델과 관절 값 매핑에 쓴다. | 범용 6축, 단위는 도 | `config/robotModel.ts`, 구조가 크게 다르면 `RobotArm` 재작성 |
| B6 | 탱크 부피(용량) 값은 센서에서 직접 받나요, 수위에서 계산하나요? | 화면에 부피(m³)를 표시한다. 무게는 쓰지 않는다. | 서버가 `volumeM3`와 `capacityM3`를 준다 | 탱크 상태 형식 |
| B7 | 알람을 FCM으로 발송해 줄 수 있나요? | 앱이 닫혀 있을 때의 알림 경로다. | 못 하면 앱이 켜져 있을 때만 알림 | 알림 방식 |
| B8 | CCTV RTSP를 HLS나 WebRTC로 변환하고 서명 주소를 발급해 줄 수 있나요? | 앱은 발급받은 주소를 `video` 태그로 재생하기만 한다. | HLS 우선, 가능하면 WebRTC | CCTV 구현 |
| B9 | 상태 종류(`status`, `phase`)와 기준값 정의, 시각의 기준(UTC 여부)은? | 화면은 서버가 판정한 `status`를 표시만 한다. | `status`: normal/caution/alarm/offline, `phase`: idle/pick/move/place, 시각은 UTC | `shared/` 타입, 표시 형식 |
| B10 | 현장에 물리 비상정지 버튼이 있나요? | 비상정지는 앱의 일이 아니다. 앱 화면에서 안전 수단처럼 보이게 하지 않기 위해 확인한다. | 있다고 가정, 앱에는 비상정지를 만들지 않는다 | 화면 문구, 안내 |
