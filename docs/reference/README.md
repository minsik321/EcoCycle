# Visual reference (Studio tab)

Frames captured from a third-party logistics dashboard video ("WareTrack"). They are **look-and-feel references only**.
Do not copy the brand name, logo, icons, texts or data. Photos were taken of a monitor, so ignore the perspective,
blur, moiré and the blurred patch at the bottom-right (a social-media overlay that was removed).

The video moves between zoom levels, so the frames are grouped by camera distance.

| File | Camera | What to learn from it |
|---|---|---|
| 01-wide-whole-site.png | Wide | The whole site still reads as calm: big white roofs, thin blue edge lines, sparse trees, lots of empty pale ground |
| 02-wide-aerial-building.png | Wide | Building-level overview with the detail panel open. Only a few vehicles, nothing crowded |
| 03-wide-dock-row.png | Wide → mid | A long dock row with blue door frames, glass facade, trucks spread out with space between them |
| 04-mid-second-site.png | Mid | The same style at another site: consistent palette and spacing |
| 05-mid-yard-pins-and-panel.png | Mid | Map pins, a small selection label on a forklift, the right detail panel for the selected forklift |
| 06-mid-site-switcher-open.png | Mid | Site switcher dropdown with mini progress bars; panels stacked without clutter |
| 07-mid-trucks-at-docks.png | Mid | Trucks queued at docks, a highlighted bay, a pin, generous floor space |
| 08-close-truck-forklift.png | Close | Hero vehicles large on screen: rounded clay forms, soft shadows, coloured stripe on white trucks |
| 09-close-forklift-pallets.png | Close | Forklift with pallets: safety yellow + kraft boxes + one blue accent, nothing else |
| 10-close-route-and-pins.png | Close | Dashed route line to a destination pin, a selected truck with a pulsing label |

Common traits across all frames:
- Near-white ground and buildings; colour only on accents (blue), vehicles / machines (yellow, coloured truck stripes) and goods (kraft / blue boxes).
- Soft ambient occlusion and contact shadows, no hard dark shadows; slightly hazy, bright lighting.
- Rounded, toy-like geometry with bevels everywhere.
- One slim top bar (logo, search, site switcher, live clock, alerts, user). No sidebar.
- Small, light UI typography: small labels, one emphasized number per KPI card, compact tables with status pills.
- Panels: frosted white glass, large radius, soft shadow, generous padding. Bottom-left process tracker with
  circular step icons on a line; bottom-right tabbed table; right detail panel; top-left 3 KPI cards.
- Camera glides between wide, mid and close views. A selected object gets a pin / label and the panel updates.
