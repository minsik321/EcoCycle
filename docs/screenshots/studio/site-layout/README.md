# 3D 홈: 실제 부지 배치 (S2d, 2026-11-24)

위성사진(위가 북쪽)을 `app/src/studio/world/layout.ts`의 `sitePx` 하나로 옮긴 3D 홈. 사진 파일 자체는 저장소에 넣지 않는다.
모든 그림은 주차 차량을 없앤 뒤(주변은 숲·도로·사무실 곁 트레일러 하나) 다시 찍었다. 찍은 방법: Chromium(SwiftShader), 배율 1. 시연 화면은 `/scene-demo?tier=standard`(예시 데이터), 실제 홈은 모의 서버 + `admin` 로그인 + 3D 홈(화질은 접속 측정값).

사진과 맞춘 배치: 북서 숲, 북서 베일 구역(ㄱ자, 고정 재고 "예시"), 사무실("태화리싸이클링" 자리)과 그 서쪽 트레일러, 사무실 바로 아래 계근대(가로로 긺),
계근대와 남동 베일 구역 사이의 입구, 동쪽 도로(북 → 남서), 가운데 빈 마당, 로봇(지금 포크레인 자리)과 그 양쪽 더미(레일을 볼 때 오른쪽 A = 북서 갈색, 왼쪽 C = 남동 흰 더미),
로봇에서 남서쪽 파란 지붕 압축기 건물로 오르는 경사 레일, 건물 남동 모서리의 배출구, 남동 베일 구역(ㄴ자, 서버 베일 적치).

`docs/screenshots/studio/yard/`(이 폴더 밖)는 S2d 이전의 옛 배치(본관·출하 마당)를 찍은 것이다. 새 배치의 장시간 점검 그림은 이 폴더의 `yard/`다.
