# 베일 클램프 외형 확인

`YARD_RETURN_OUT=yard-clamp`로 `app/scripts/yardReturn.mjs`를 실행한 브라우저 캡처다. 지게차의 바닥 포크를 양옆 클램프 판으로 교체하고, 잡기 전에 닫고 적치 후 여는 동작을 추가했다.

화면의 많은 베일은 재현 스크립트가 주입한 **20초마다 생성·출하 없음** 조건이다. 정상 서버에서 화면을 비웠을 때 이렇게 쌓인다는 뜻이 아니다. 패널은 별도 시연 데이터다.

- `01-return-floating.png`: 열린 클램프 외형과 기존 공중 적치 현상 재현.
- `02-after-placement.png`: 클램프로 운반해 아래 칸을 채운 상태.
- `report.json`: 재현 수치. 아래 칸 배치까지 시뮬레이션 약 7.45초, 겹침 0건.
