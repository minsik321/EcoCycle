# 고정 베일 3개

`node app/scripts/yardStatic.mjs`로 정상 시연 화면을 캡처했다. 출하를 막거나 동적 베일을 대량 주입하지 않았다.

지게차 대기 공간 옆 본관 서쪽 가장자리에 고정 베일 3개를 바닥에 배치했다. 배경 소품이므로 생산·출하·재고 수량에는 포함되지 않는다.

검증:
- 모의 서버 자동 출하는 기존 생성 25초 후 처리를 유지한다.
- `node --import tsx mock-server/scripts/checkAutoShip.ts`: 브라우저 연결 없이 30분 시뮬레이션, 59개 생산·58개 출하·미출하 최대 1개. 이후 서버 시간 10분 진행 시 기존 대기분 출하 완료.
- 지게차 10분 시뮬레이션에서 고정 베일과 차체/집게/운반 베일의 바닥 투영 69,615회 검사, 겹침 0건.
- 전체 워크스페이스 타입 검사 통과.
