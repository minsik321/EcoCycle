# 로봇팔 — 6단위

재현: 루트에서 `node app/scripts/robotArm.mjs`. 로컬 Chromium과 모의 서버를 사용한다.

- `390x844-*`, `820x1180-*`: 요청 크기별 자동, 수동, 수동 집기 정렬, 지정 확인, 지정 자동, 집기 기록. 2026-10-16부터 운전 모드는 세 칸 하나(자동 | 자동 · 섹터 지정 | 수동)라 새 조작으로 다시 찍었다(`docs/screenshots/device-pages`에도 세 모드가 있다).
- `-1-`: 글자 100%, `-1.3-`: 글자 130%. `-full`은 같은 뷰포트에서 페이지 전체를 촬영한 참고 이미지다.
- `validation.txt`: 실제 명령·사이클, 확인·취소, 섹터 변경·지정 해제, 권한 403, 입력 422, 멱등성, 글 줄바꿈·표 가로 넘침 점검 결과.

사이클 통계는 기존 안내를 유지하고, 그 아래에 별도 집기 RecordList를 추가했다. 예시 데이터이며 실제 장비 검증은 포함하지 않는다.

전체 `npm run test:text`에도 세 모드·확인·기록 점검이 들어 있다(새 조작으로 고침).
